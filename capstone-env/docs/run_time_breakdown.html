Where a run's time goes

94% of every run is the model generating tokens, and about two thirds of those tokens are thinking. The harness, the tools, Docker, the network and reading the prompt together take about 6%.

Why one run takes 8.4 minutes and not 5

~5 min aloneone run at a time: 19.7 tok/s for the run
8.4 min shared4 at a time: 12.4 tok/s for each run
2.3× more runs/hourthe server makes ~45 tok/s instead of 19.7

A run is slower on its own because 4 runs share one GPU, but the whole job finishes much sooner. The job's length is total tokens ÷ server speed: 216 runs × 5,769 tokens ÷ 45 tok/s ≈ 7.7 hours.
