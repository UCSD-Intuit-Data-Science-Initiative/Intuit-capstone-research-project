## Notes for Stage 4

- `metric_scale`: `fraction` (0.0174 = 1.74%), `percent` (program ends ×100) or `amount` (difference; see `unit`). Thresholds must use that scale.
- `numerator_inputs` / `denominator_inputs` (growth_rate, ratio) and `inputs` (with role: numerator, denominator, minuend, subtrahend) give each input's cell (row, col, label, text).
- `n_irrelevant_cells` counts cells safe to edit for version 4.
- Total detection only recognises rows/columns labelled "total".
